# CycleContext

CycleContext is an iPhone and iPad app for understanding cycle patterns, recording personal observations, and offering respectful support.

The app is available on the [App Store](https://apps.apple.com/app/id6804225862).

## Build

1. Open `CycleContext.xcodeproj` in Xcode.
2. Choose the `CycleContext` or `CycleContext-EN` scheme.
3. Run on an iOS simulator or device supported by the project.

`CycleContext.storekit` contains the StoreKit configuration used for local purchase testing. For device signing, select an Apple Developer team in Xcode.

## Technologies

- Swift and SwiftUI
- StoreKit
- Localized interface resources
